# 안개등 — 등대지기가 남긴 서른 개의 암호

사물을 빛에 겹쳐 글자를 찾고, 등대지기의 일기 서른 줄을 해독하는 퍼즐 게임입니다. 규칙은 한 줄, 푸는 재미는 서른 단계.

**플레이:** https://fifa3827-lgtm.github.io/foglamp/

- PC는 전체화면, 모바일은 가로 화면. 스크롤 없음. 파일 하나(index.html)로 동작하며 음악·효과음은 브라우저 안에서 합성합니다.
- 퍼즐을 좋아하는 누구나. 진행은 기기에 저장됩니다.

## 규칙

탁자 위의 물건을 앞·뒤 자리에 올리면 빛판에 모양이 찍힙니다. 그 모양이 한글 자모와 정확히 같으면(자리는 상관없음) 노트의 쟁반에 들어옵니다. 쟁반의 자모로 일기의 빈 글자를 채우고 「해독」을 누르세요. 문장 전체가 맞아야 안개가 걷힙니다.

| 도구 | 뜻 | 등장 |
|---|---|---|
| 비추기 ∩ | 두 사물이 모두 뚫린 곳만 남는다 | 1막 |
| 돌리기 ↻ | 사물을 90°씩 돌린다 | 2막 |
| 겹치기 ∪ | 두 모양을 합친다 | 3막 |
| 파내기 −, 뒤집기 ⇋ | 앞에서 뒤 모양을 도려낸다 / 거울에 비춘다 | 4막 |
| 간직하기 ✦ | 빛판의 모양을 새 사물로 만든다(단계마다 셋) | 5막 |
| 밀기 ←→↑↓ | 사물을 한 칸씩 옮긴다. 판 밖으로는 나가지 않는다 | 6막 |

점 일곱 개는 가장 가까운 글자까지 남은 칸 수. 힌트는 단계마다 세 번.

## 만든 방식

사물과 자모는 7×7 비트맵입니다. 생성기(gen.js)가 모든 사물 쌍 × 변형 × 조합을 열거해, 단계마다 "필요한 자모가 모두 나올 수 있고, 새 도구가 실제로 필요하며, 함정 자모 수가 허용 범위 안"임을 검증한 뒤 단계 데이터를 심었습니다. 이어서 게임 코드 자체로 서른 단계를 자동 풀이해 확인했습니다. (간직하기 단계의 함정 수는 하한값입니다.)
